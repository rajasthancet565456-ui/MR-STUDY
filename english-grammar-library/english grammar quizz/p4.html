1. Imperative + Object

Active: Open the door.
Passive: Let + object + be + V3
→ Let the door be opened.

2. Imperative without Object

Use an order/request structure: You are ordered/requested/forbidden to + V1.

3. Moral Suggestion

Object + should + be + V3
Help the poor → The poor should be helped.

4. Infinitive

to + V1 → to + be + V3
I am to do it → It is to be done by me.

5. Have / Has / Had + to + V1

Object + have/has/had + to + be + V3
I have to finish it → It has to be finished by me.

6. Let / Bid / Help / Make

Active generally uses direct infinitive without “to”.
Passive uses to + V1.

7. Let has different meanings

Permission, ordinary passive construction, suggestion/advice can produce different passive forms.

8. Verb + Adjective

Rose smells sweet → Rose is sweet when it is smelt.
Quinine tastes bitter → Quinine is bitter when it is tasted.
