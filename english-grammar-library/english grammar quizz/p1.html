1. Active Voice

Active Voice tells us that the subject performs the action.

Subject + Verb + Object

2. Passive Voice

Passive Voice emphasizes the object/person affected by the action.

Object + Helping Verb + V3 + by + Subject

The helping verb changes according to tense.

3. Simple Present

ACTIVE
Subject + V1 + Object
PASSIVE
Object + is/am/are + V3 + by + Subject

4. Simple Past

ACTIVE
Subject + V2 + Object
PASSIVE
Object + was/were + V3 + by + Subject

5. Simple Future

ACTIVE
Subject + will/shall + V1 + Object
PASSIVE
Object + will/shall + be + V3 + by + Subject

6. Modal

ACTIVE
Subject + Modal + V1 + Object
PASSIVE
Object + Modal + be + V3 + by + Subject

7. When Passive Voice is useful

  • When the action is more important than the doer.
  • When the doer is unknown.
  • When the doer is not important or obvious.
